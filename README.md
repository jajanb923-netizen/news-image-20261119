Sum up 19 November's world news in one image: a one-page newspaper front page for Thursday 19 November 2026 — the Trump–Xi–Putin summit in Shenzhen, the International Court of Justice's genocide ruling on Myanmar, the GTA VI launch, Anthropic's Nasdaq debut, the strike on the Crimea bridge, and a ticker of the day's other stories. The image is drawn by `draw.py` (Pillow) from the day's real reporting, and `main.py` copies it to `/output/entry.png`.

## Run it

```sh
python3 main.py
```

Local run (writes to `./out/entry.png` instead of `/output/entry.png`):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
